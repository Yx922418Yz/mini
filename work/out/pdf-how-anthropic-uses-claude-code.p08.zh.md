# Claude Code 用于增长营销（续）

（原文页码：16）

## 团队成效

- **重复性任务大幅省时**：广告文案创作从 2 小时缩短到 15 分钟，腾出时间做战略性工作。
- **创意产出提升 10 倍**：借助自动化生成与 Figma 集成，团队如今能在各渠道上测试多得多的广告变体。
- **像一支更大的团队那样运转**：团队能够承接以往需要专门工程资源才能完成的任务。
- **战略重心转移**：团队能把更多时间花在整体战略和构建智能体式自动化上，而不是手动执行。

## 增长营销团队的核心提示

- **识别可 API 化的重复性任务**：寻找那些涉及重复操作、且所用工具带有 API 的工作流（如广告平台、设计工具、分析平台）。这些是自动化的首选对象，也是 Claude Code 价值最大的地方。
- **把复杂工作流拆分为专门的子智能体**：不要试图用一个提示或工作流包办一切，而要为具体任务创建独立的智能体（例如他们的标题智能体与描述智能体）。这样更易调试，在处理复杂需求时也能提升输出质量。
- **编码前充分头脑风暴并规划提示**：先花大量时间用 Claude.ai 把整个工作流想透，再让 Claude.ai 为 Claude Code 生成一份完整提示和代码结构供其参考。同时要一步步来，而不是索要一步到位的方案，以免 Claude 被复杂任务压垮。

# Claude Code 用于产品设计

（原文页码：17）

产品设计团队支持 Claude Code、Claude.ai 和 Anthropic API，专长是构建 AI 产品。即便是非开发者，也能用 Claude Code 跨越设计与工程之间的传统鸿沟，无需与工程师反复沟通，就能直接把自己的设计设想落地实现。

## Claude Code 主要用例

- **前端打磨与状态管理改动**：以往为了视觉微调（字体、颜色、间距），他们要写大量设计文档并与工程师反复反馈；如今他们直接用 Claude Code 实现这些改动。工程师评价说，他们正在做“通常你不会看到设计师去做的大规模状态管理改动”，从而实现了他们心中设想的确切品质。
- **GitHub Actions 自动建单**：借助 Claude Code 的 GitHub 集成，他们只需提交描述所需改动的 issue/工单，Claude 便会自动给出代码方案，甚至不必打开 Claude Code，从而为长期积压的打磨类任务打造了一条顺滑的缺陷修复与功能完善流程。
- **快速交互式原型**：把设计稿图片粘贴进 Claude Code，就能生成功能完整的原型，工程师可立即理解并在此基础上迭代，取代了过去“静态 Figma 设计 + 大量解释 + 翻译成可运行代码”的传统循环。
- **边界情况发现与系统架构理解**：他们用 Claude Code 梳理错误状态、逻辑流转和不同的系统状态，从而在**设计阶段**就发现边界情况，而不是等到开发后期才发现，从根本上提升了初始设计的质量。
- **复杂文案改动与法律合规**：对于诸如在整个代码库中移除“research preview”措辞这类任务，他们用 Claude Code 找出所有出现位置、审阅周边文案、与法务实时协同并实施更新——整个过程只用了两次 30 分钟的通话，而不是一周的来回协调。
