# 安全工程中的 Claude Code（续）

（原文页码：8）

## 团队成效

- **事件解决时间缩短**：原本需要 10–15 分钟人工扫读代码的基础设施调试，现在约 5 分钟即可完成。
- **安全评审周期改善**：用于安全审批的 Terraform 代码评审显著加快，开发者不再因等待安全团队批准而被阻塞。
- **跨职能贡献增强**：团队成员能在几天内（而非花上几周积累上下文后）对项目做出有意义的贡献。
- **文档工作流更佳**：从多个来源综合出故障排查指南与运行手册，形成更高效的调试流程。

## 安全工程团队的核心提示

- **大量使用自定义斜杠命令**：整个单体仓库中所有自定义斜杠命令的实现，有 50% 出自安全工程团队。这些自定义命令精简了特定工作流，加速了重复性任务。
- **先让 Claude 说**：他们不再针对代码片段提出定向问题，而是让 Claude Code“边做边提交工作”（commit your work as you go），让它自主工作并定期汇报进展，从而得到更全面的解决方案。
- **善用它做文档**：除了编码，Claude Code 在综合文档、生成结构化输出方面同样出色。他们提供写作样本和格式偏好，就能得到可直接用于 Slack、Google Docs 等工具的文档，避免在多个界面间来回切换带来的疲劳。

# 推理（Inference）团队中的 Claude Code

（原文页码：9）

推理团队负责管理记忆系统——即在 Claude 读取你的提示并生成回复的过程中用于存储信息的系统。团队成员（尤其是机器学习新手）可以大量使用 Claude Code 来弥合知识差距、加速工作。

## Claude Code 主要用例

- **代码库理解与上手**：该团队高度依赖 Claude Code，在加入复杂代码库时快速理解其架构。他们不再手动检索 GitHub 仓库，而是让 Claude 找出哪些文件调用了特定功能，几秒钟就能得到结果，无需询问同事或手动检索。
- **覆盖边界情况的单元测试生成**：写完核心功能后，他们让 Claude 编写全面的单元测试。Claude 会自动补上被遗漏的边界情况，把原本需要耗费大量脑力的工作压缩到几分钟内完成，就像一个可供评审的编程助手。
- **机器学习概念解释**：没有机器学习背景的团队成员依赖 Claude 解释特定于模型的函数与设置。原本需要一小时 Google 检索和阅读文档的事，现在 10–20 分钟即可完成，研究时间减少 80%。
- **跨语言代码翻译**：在不同编程语言中测试功能时，他们说明想测试什么，Claude 就用所需的语言（如 Rust）写出逻辑，免去了仅为测试而学习新语言的需要。
- **命令回忆与 Kubernetes 管理**：他们不再死记复杂的 Kubernetes 命令，而是直接问 Claude 正确的语法，例如“如何查看所有 pod 或 deployment 状态”，从而获得基础设施工作所需的准确命令。
