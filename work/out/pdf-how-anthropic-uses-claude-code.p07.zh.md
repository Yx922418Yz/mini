# Claude Code 用于 API（续）

（原文页码：14）

## 团队成效

- **增强了对不熟悉领域的处理信心**：团队成员能够独立调试缺陷、排查事故，哪怕面对的是陌生的代码库。
- **上下文收集显著省时**：省去了复制代码片段、把文件拖进 Claude.ai 的开销，降低了上下文切换带来的心智负担。
- **更快的轮岗上手**：轮岗到新团队的工程师能迅速熟悉陌生代码库，无需大量咨询同事就能做出有意义的贡献。
- **提升开发者幸福感**：团队反馈日常工作中的摩擦减少，人更开心、也更高效。

## API 知识团队的核心提示

- **把它当作迭代伙伴，而非一次性方案**：不要指望 Claude 一次就能解决问题，而要把它当成一个与你反复迭代的协作者。这比强求第一次就得到完美方案效果更好。
- **用它来在不熟悉的领域建立信心**：不要害怕去处理专业领域之外的缺陷或排查事故——Claude Code 让那些本需要大量上下文积累才能独立开展的工作变得可行。
- **从最少信息开始**：只需给出你真正需要的最低限度信息，让 Claude 引导你走完流程，而不是一上来就堆砌大量解释。

# Claude Code 用于增长营销

（原文页码：15）

增长营销团队专注于在付费搜索、付费社交、移动应用商店、邮件营销和 SEO 上搭建效果营销渠道。作为一个只有一人的非技术团队，他们用 Claude Code 来自动化重复的营销任务，并创建出以往需要大量工程资源才能实现的智能体式工作流。

## Claude Code 主要用例

- **自动化生成 Google Ads 创意**：团队构建了一个智能体式工作流，用于处理包含数百条现有广告及其效果指标的 CSV 文件，识别出表现不佳、需要迭代的广告，并生成符合严格字数限制（标题 30 字符、描述 90 字符）的新变体。该工作流使用两个专门化的子智能体（一个负责标题，一个负责描述），几分钟内就能生成数百条新广告，而无需在多个广告系列中手动创建。这让他们得以大规模地测试和迭代，而这在以前需要耗费大量时间才能做到。
- **用于批量创意生产的 Figma 插件**：他们不再手动复制、编辑静态图片来做付费社交广告，而是开发了一个 Figma 插件，能识别画板（frame）并通过替换标题与描述，程序化地生成多达 100 个广告变体，把原本要花数小时复制粘贴的工作压缩到每批半秒钟。这让创意产出提升到 10 倍，使团队能在关键社交渠道上测试多得多的创意变体。
- **用于广告投放分析的 Meta Ads MCP 服务器**：他们创建了一个与 Meta Ads API 集成的 MCP 服务器，可直接在 Claude Desktop 应用内查询广告系列表现、花费数据和广告效果，免去了为做效果分析而在不同平台间来回切换，节省了关键时间——在这里，每一分效率提升都转化为更好的 ROI。
- **结合记忆系统的高级提示工程**：他们实现了一个简易的记忆系统，记录各轮广告迭代中的假设与实验，使系统在生成新变体时能把以往的测试结果拉入上下文，从而形成一个可自我改进的测试框架。这实现了手动根本无法追踪的系统化实验。
