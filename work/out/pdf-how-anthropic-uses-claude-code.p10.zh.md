# Claude Code 用于强化学习工程（续）

（原文页码：20）

## 开发工作流影响

- **支持了实验式方法**：他们现在采用“先试再回滚”的方法论，频繁提交检查点，以便测试 Claude 的自主实现尝试并在需要时回滚，从而支持更具实验性的做法。
- **文档加速**：Claude Code 会自动补充有用的注释，在文档上节省大量时间；不过他们指出，它有时会把注释加在奇怪的位置，或采用值得商榷的代码组织方式。
- **提速但仍有局限**：虽然 Claude Code 能让他们投入“相对较少的时间”就实现中小型 PR，但团队承认它只有约三分之一的情况能一次成功，其余时候需要额外指导或人工介入。

## 强化学习工程团队的核心提示

- **针对特定模式自定义你的 Claude.md 文件**：在 Claude.md 中加入指令，防止 Claude 反复犯同样的工具调用错误，比如告诉它“用 pytest 来运行，而不是 run；不要不必要地 cd——直接用正确的路径”。这显著提升了一致性。
- **采用重检查点的工作流**：在 Claude 做改动时定期提交你的工作，这样实验不奏效时就能轻松回滚。这让你能无风险地采用更偏实验性的开发方式。
- **先试一次性方案，再转为协作**：给 Claude 一个简短提示，让它先尝试完整实现。如果成功（约三分之一的情况），你就省下了大量时间；如果失败，再切换到更协作、更有引导的方式。

# Claude Code 用于法务

（原文页码：21）

法务团队是通过不断实验、以及出于了解 Anthropic 产品线的意愿而发现 Claude Code 潜力的。此外，一位团队成员还有一个个人用例：为家人创建无障碍工具，以及展示该技术对非开发者有多大威力的工作原型。

## Claude Code 主要用例

- **为家人定制的无障碍解决方案**：团队成员为因医疗诊断而说话困难的家人构建了沟通助手。仅用一小时，他们就做出了一款预测式文本应用，它使用原生语音转文字功能给出回复建议，并用语音库把建议朗读出来，填补了言语治疗师所推荐的无障碍工具存在的空白。
- **法务部门工作流自动化**：他们制作了原型“电话树”系统，帮助团队成员联系到 Anthropic 合适的律师，展示了法务部门如何在无需传统开发资源的情况下，为常见任务构建自定义工具。
- **团队协同工具**：管理者构建了 G Suite 应用，自动完成每周团队更新，并跟踪各产品的法务审查状态，让律师只需简单点击按钮——而不用管理电子表格——就能快速标记出需要审查的条目。
- **用于方案验证的快速原型**：他们用 Claude Code 快速构建可展示给领域专家（比如把无障碍工具展示给 UCSF 的专家）的功能原型，以便在投入更多时间之前验证想法、识别已有解决方案。
